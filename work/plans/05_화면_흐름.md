# 화면 흐름

## 기본 원칙

첫 화면은 관리 화면이 아니라 `지금 해야 할 일`을 알려주는 화면이다.
목록, 검색, 필터, 수정/삭제 버튼은 첫 화면에서 최소화한다.

## 학생 화면 흐름

```text
이번 주
 -> 오늘
 -> 공부 중
 -> 완료 피드백
 -> 다음 행동
 -> 하루 마감
```

### 0. 이번 주

장기 계획에서 내려온 이번 주 흐름을 학생이 부담 없이 보는 화면이다.

- 시험 또는 루틴 이름
- 이번 주에 챙길 과목 2~4개
- 매일 반복 항목
- 오늘로 이어지는 첫 행동
- 무리한 계획이 아닌지에 대한 짧은 메시지

이 화면은 달력형 관리 화면이 아니라 주간 흐름 요약이어야 한다.

## 학생 일일 실행 흐름

```text
오늘
 -> 공부 중
 -> 완료 피드백
 -> 다음 행동
 -> 하루 마감
```

### 1. 오늘

학생의 기본 홈 화면이다.

- 현재 상태 메시지
- 지금 할 일 1개
- 남은 공부 시간
- 다음 고정 일정
- 시작 버튼
- 쉬는 중이면 종료 전 안내

이 화면에는 테이블을 두지 않는다.

### 2. 공부 중

공부를 시작한 뒤의 집중 화면이다.

- 현재 공부 항목
- 남은 시간
- 종료 예상 시각
- 끝냈어요 버튼
- 잠깐 멈춤 또는 도움 요청

### 3. 완료 피드백

공부 완료 직후의 짧은 화면이다.

- 완료 축하
- 다음 행동
- 쉴 수 있는 시간
- 오늘 계획 회복 상태

### 4. 하루 마감

취침 전 또는 부모 확인 전의 정리 화면이다.

- 오늘 끝낸 것
- 내일로 넘길 것
- 무리했던 계획 여부
- 짧은 코치 메시지

## 부모 화면 흐름

```text
부모 안심
 -> 장기 계획
 -> 이번 주 조정
 -> 오늘 계획 조정
 -> 알림 설정
 -> 하루 마감 요약
```

### 1. 부모 안심

부모의 기본 홈 화면이다.

- 현재 상태 한 문장
- 개입 필요 여부
- 오늘 완료/남은 공부량
- 회복 가능 여부
- 다음 일정

상세 로그를 첫 화면에 노출하지 않는다.

### 2. 오늘 계획 조정

부모가 공부 항목과 생활 일정을 조정하는 화면이다.

- 오늘 공부 항목
- 예상 소요시간
- 고정 일정
- 놀이/휴식 허용 시간
- 저장 후 현실성 판단

### 2-1. 장기 계획

시험, 수행평가, 반복 루틴을 등록하는 화면이다.
화면 제목은 `계획 관리`보다 `시험 준비 만들기`, `평소 루틴 만들기`처럼 생활 언어를 사용한다.

- 시험명
- 시험 시작일과 종료일
- 시험일차별 과목
- 시험 대비 시작일
- 과목별 중요도 또는 기본 공부 시간
- 평시 반복 루틴

### 2-2. 이번 주 조정

자동 생성된 주간 계획을 부모가 확인하고 다듬는 화면이다.

- 이번 주 과목 균형
- 요일별 부담 정도
- 가용 시간이 부족한 날
- 앱의 조정 제안
- 조정 후 학생 화면 미리보기

표를 전면에 두기보다 과목 균형과 부담도를 먼저 보여준다.

### 3. 알림 설정

부모 알림의 강도를 조정한다.

- 지연 몇 분 후 알림
- 회복 불가 예상 시 알림
- 하루 마감 요약 알림
- 학생에게 먼저 보낼 회복 알림 횟수

### 4. 하루 마감 요약

부모가 하루를 판단하는 화면이다.

- 완료한 공부
- 미완료 또는 이동된 공부
- 계획이 무리했는지
- 내일 조정 제안

## 공통 보조 화면

### 가족 설정

- 부모/학생 프로필
- 역할
- 기본 취침 시간
- 기본 등교/학원 일정

### 시험 준비 만들기

- 시험 일정 입력
- 시험일차별 과목 입력
- 대비기간 확인
- 과목별 공부 시간 자동안 확인
- 주간 배분 확인

### 평소 루틴 만들기

- 요일별 과목 설정
- 매일 반복 암기 설정
- 루틴 적용 기간 설정
- 시험 대비기간 전환 방식 설정

### 계획 조정 요청

학생이 오늘 계획을 줄이거나 옮기고 싶을 때 사용한다.

- 요청 사유
- 앱 추천 조정안
- 부모 승인 상태

## 피해야 할 화면 구조

- 첫 화면에서 공부 항목 전체를 표로 보여주는 구조
- `사용자 관리`, `일정 관리`, `알림 관리` 메뉴가 전면에 나오는 구조
- 상태 배지와 수정/삭제 버튼이 반복되는 구조
- 완료율 그래프가 다음 행동보다 먼저 보이는 구조
- 장기 계획을 월간 표 전체로 먼저 보여주는 구조
- 시험 과목별 행과 수정 버튼이 반복되는 구조
