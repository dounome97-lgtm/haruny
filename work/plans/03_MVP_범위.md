# MVP 범위

## MVP 한 문장 정의

학생이 장기 학습 목표를 오늘의 작은 행동으로 실행할 수 있게 돕고, 오늘 계획을 끝내기 위해 지금 무엇을 해야 하는지 알려주며, 부모에게는 필요한 수준의 안심 요약과 계획 현실성 판단을 제공하는 앱.

## 핵심 사용자

- 학생: 초등 고학년~중학생
- 부모: 학생의 하루 계획과 학습 루틴을 함께 관리하는 보호자

## MVP 1차 개발 범위

1차 MVP는 제품의 핵심 가설을 가장 빠르게 검증하는 범위로 고정한다.
이 범위를 벗어나는 기능은 문서에 있더라도 1차 개발에서는 후순위로 둔다.

### 1차 MVP에 포함할 것

- 학생용 `오늘` 화면
- 학생용 `이번 주` 화면
- 부모용 `시험 준비 만들기`
- 부모용 `평시 루틴 만들기`
- 장기 계획에서 오늘 공부 자동 생성
- 공부 시작/완료 체크
- 남은 시간 계산

### 1차 MVP에서 제외할 것

- 실제 푸시 알림 연동
- 위치 추적
- 휴대폰 사용 시간 수집
- AI 자유 대화
- 장기 성적 분석
- 고급 통계
- 앱스토어/플레이스토어 배포
- 결제/구독
- 교사용 또는 학원용 관리자 기능

### 1차 MVP의 판단 기준

- 학생이 앱을 열었을 때 `오늘 지금 할 일`이 바로 보인다.
- 장기 계획이 학생에게 부담스러운 계획표가 아니라 오늘 공부로 내려온다.
- 한 달 시험 계획이 4주 전, 3주 전, 2주 전, 1주 전 단계로 나뉜다.
- 주간 계획은 하루 실패를 흡수하는 현실 조정 장치로 동작한다.
- 일일 계획은 시간표가 아니라 필수/추가/남으면 미션으로 보인다.
- 부모가 시험 일정과 평시 루틴을 만들 수 있다.
- 공부 시작/완료가 기록된다.
- 남은 시간 계산으로 오늘 계획의 현실성을 판단할 수 있다.
- 전체 화면이 백오피스가 아니라 모바일 생활 코치 앱처럼 느껴진다.

## MVP에 포함할 것

### 학생 경험

- 오늘 상태 확인
- 지금 할 일 추천
- 공부 시작/완료 체크
- 남은 공부량과 남은 가능 시간 확인
- 시험/루틴에서 내려온 오늘 공부 확인
- 이번 주에 챙겨야 할 과목 흐름 확인
- 놀이/휴식 종료 전 알림
- 늦어졌을 때 회복 계획 제안
- 하루 마감 확인

### 부모 경험

- 장기 학습 목표 등록
- 시험 일정과 시험 과목 등록
- 평시 반복 루틴 등록
- 시험 대비기간 자동 생성 확인
- 주간/일간 공부 배분 자동안 확인
- 오늘 계획 등록 또는 조정
- 학생의 현재 상태 요약 확인
- 오늘 계획이 현실적인지 확인
- 반복 지연 또는 미완료 예상 시 알림
- 하루 마감 요약 확인

### 시스템 기능

- 공부 항목별 예상 소요시간 관리
- 장기 목표를 월간/주간/일간 계획으로 분해
- 시험 주차별 학습 전략 적용
- 시험 일정 기반 시험 대비기간 생성
- 요일별 반복 루틴 기반 공부 항목 생성
- 과목별 공부 시간 배분
- 일일 미션을 필수/추가/남으면 단계로 분류
- 취침, 등교, 학원, 식사, 놀이 등 시간 블록 관리
- 현재 시각 기준 남은 가용 시간 계산
- 오늘 계획 완료를 위한 최소 시작 시각 계산
- 알림 조건 판단
- 학생 회복 기회 단계 관리

## MVP에서 제외할 것

- 실시간 위치 추적
- 휴대폰 사용 시간 자동 수집
- 특정 앱 차단
- 학교/학원 출결 자동 확인
- 고도화된 AI 자유 대화
- 장기 성적 분석
- 세부 시험 범위 기반 난이도 자동 분석
- 학교별 시험 시간표 자동 수집
- 여러 자녀 간 경쟁/랭킹
- 교사용 또는 학원용 관리자 페이지
- 결제, 구독, 마케팅 페이지

## MVP 성공 기준

- 학생이 첫 화면에서 3초 안에 지금 할 일을 알 수 있다.
- 장기 목표가 있어도 학생 화면은 오늘 행동 중심으로 유지된다.
- 시험 한 달 전부터 과목별 준비량이 주간/일간으로 자동 분해된다.
- 시험 2주 전부터 새로운 학습보다 반복, 회독, 오답, 암기 중심으로 전환된다.
- 시험 1주 전에는 학생이 무엇을 할지 고민하지 않도록 미션이 명확해진다.
- 평시 루틴과 시험 대비기간이 자연스럽게 전환된다.
- 부모가 아이에게 직접 묻지 않고도 오늘 흐름을 이해할 수 있다.
- 계획이 늦어졌을 때 앱이 `실패`가 아니라 `회복 방법`을 제안한다.
- 공부 시작/완료 기록이 부담 없이 남는다.
- 첫 화면이 관리자 페이지나 백오피스처럼 보이지 않는다.

## 핵심 계산

MVP의 핵심 계산은 다음 네 가지다.

- 장기 목표에서 오늘 공부량으로 내려오는 배분
- 시험일까지 남은 기간과 과목별 필요 학습량
- 시험 주차에 따른 학습 강도와 미션 성격
- 주간 목표 총량과 보정 가능량
- 오늘 남은 공부 시간
- 오늘 남은 가용 시간
- 계획 완료를 위한 최소 시작 시각
- 현재 지연 상태와 회복 가능 여부

## MVP 정책

- 알림은 학생에게 먼저 보낸다.
- 학생이 회복 가능한 범위에 있으면 부모에게 즉시 알리지 않는다.
- 부모 알림은 반복 지연, 회복 불가 예상, 취침 시간 영향이 있을 때 우선한다.
- 학생 화면에서는 전체 통계보다 다음 행동을 우선한다.
- 부모 화면에서는 상세 로그보다 요약과 개입 필요 여부를 우선한다.
- 장기 계획은 부모가 조정하되, 학생에게는 오늘/이번 주 중심으로 보여준다.
- 시험 대비기간에는 평시 루틴을 자동으로 축소하거나 시험 과목 중심으로 재배치한다.
- 시험 4주 전은 루틴 유지와 개념 빈틈 확인을 우선한다.
- 시험 3주 전은 문제풀이 시작을 우선한다.
- 시험 2주 전은 시험범위 집중 회독을 우선한다.
- 시험 1주 전은 암기, 오답, 실전, 판단 제거를 우선한다.
- 일일 계획은 시간표보다 미션 방식으로 제시한다.
