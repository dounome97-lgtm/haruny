# 사용자 장면

## 장면 1. 학생이 하교 후 앱을 열었다

### 상황

학생은 학교를 마치고 집에 왔다. 오늘 해야 할 공부가 있지만 아직 무엇부터 해야 할지 모른다.

### 앱이 해야 할 일

- 현재 시간이 공부 시작을 요구하는지 판단한다.
- 다음 일정까지 남은 시간을 보여준다.
- 가장 먼저 시작할 수 있는 공부 하나를 추천한다.
- 시작 버튼을 크게 제공한다.

### 예시 메시지

```text
지금 수학 25분부터 시작하면 좋아요.
학원 전까지 영어 단어까지 끝낼 수 있어요.
```

## 장면 1-1. 부모가 기말고사 일정을 등록한다

### 상황

8월 20일부터 기말고사가 시작된다.
1일차는 국어, 사회, 도덕이고 2일차는 수학, 과학, 역사이며 3일차는 영어, 기술가정이다.

### 앱이 해야 할 일

- 시험명과 날짜를 입력받는다.
- 시험일차별 과목을 쉽게 추가하게 한다.
- 시험 한 달 전부터 대비기간을 자동 제안한다.
- 과목별 기본 공부 시간을 제안한다.
- 부모가 주간 배분을 조정할 수 있게 한다.

### 예시 메시지

```text
기말고사까지 30일 준비안이 만들어졌어요.
이번 주는 국어, 수학, 영어를 먼저 가볍게 시작하고 매일 영어 단어 15분을 유지해요.
```

## 장면 1-2. 평시 루틴을 설정한다

### 상황

시험 기간이 아닐 때도 월수금에는 수학/영어, 화목토에는 국어/사회, 매일 영어 단어와 숙어를 반복하고 싶다.

### 앱이 해야 할 일

- 요일별 과목 루틴을 설정한다.
- 매일 반복 암기 항목을 설정한다.
- 하루 가용 시간을 넘지 않는지 확인한다.
- 시험 대비기간이 시작되면 루틴 조정안을 제안한다.

### 예시 메시지

```text
평소 루틴은 월수금 수학/영어, 화목토 국어/사회로 잡았어요.
영어 단어와 숙어는 매일 15분씩 이어가요.
```

## 장면 1-3. 시험 대비기간 첫 주가 시작됐다

### 상황

시험 한 달 전이 되어 평시 루틴에서 시험 대비 모드로 전환된다.

### 앱이 해야 할 일

- 이번 주에 챙길 과목을 요약한다.
- 평시 루틴 중 유지할 것과 줄일 것을 제안한다.
- 학생에게는 오늘 할 일로만 보여준다.

### 예시 메시지

```text
이번 주부터 기말 준비를 조금씩 시작해요.
오늘은 사회 25분, 영어 단어 15분만 챙기면 충분해요.
```

## 장면 2. 놀이 시간이 끝나기 10분 전이다

### 상황

부모가 허용한 놀이 시간이 곧 끝난다.

### 앱이 해야 할 일

- 종료 10분 전 부드럽게 예고한다.
- 종료 시점에 다음 행동을 안내한다.
- 바로 공부로 넘어가기 어렵다면 짧은 전환 시간을 제안한다.

### 예시 메시지

```text
놀이 시간이 10분 남았어요. 끝나면 영어 단어 15분부터 가볍게 시작해요.
```

## 장면 3. 공부 시작 시간이 지났다

### 상황

학생이 공부를 시작하지 않았고, 오늘 계획이 조금 밀리기 시작했다.

### 앱이 해야 할 일

- 먼저 학생에게 회복 가능한 선택지를 준다.
- 부모에게 즉시 알리지 않는다.
- 짧은 항목부터 시작하도록 제안한다.

### 예시 메시지

```text
조금 늦었지만 아직 괜찮아요.
지금 15분짜리 영어부터 시작하면 오늘 계획을 회복할 수 있어요.
```

## 장면 4. 오늘 계획을 모두 끝내기 어려워졌다

### 상황

남은 가용 시간이 부족해졌다.

### 앱이 해야 할 일

- 학생에게 현실적인 축소안을 제안한다.
- 부모에게는 `계획 조정 필요`로 요약한다.
- 비난하는 표현을 쓰지 않는다.

### 예시 메시지

```text
오늘은 전부 끝내기 어려워 보여요.
수학 20분은 오늘 하고, 독서는 내일로 옮기는 안을 부모님께 요청할 수 있어요.
```

## 장면 5. 학생이 공부를 시작했다

### 상황

학생이 시작 버튼을 눌렀다.

### 앱이 해야 할 일

- 진행 중 화면으로 전환한다.
- 남은 시간과 종료 예상 시각을 보여준다.
- 완료 버튼을 명확히 제공한다.
- 중간에 과도한 정보를 보여주지 않는다.

### 예시 메시지

```text
수학 25분 진행 중이에요.
끝나면 5분 쉬고 영어 단어로 넘어가요.
```

## 장면 6. 학생이 공부를 완료했다

### 상황

학생이 완료 버튼을 눌렀다.

### 앱이 해야 할 일

- 즉시 긍정 피드백을 준다.
- 다음 행동을 안내한다.
- 남은 계획을 압박적으로 나열하지 않는다.

### 예시 메시지

```text
좋아요. 수학은 끝났어요.
5분 쉬고 영어 단어 15분만 하면 오늘 계획이 훨씬 가벼워져요.
```

## 장면 7. 부모가 퇴근길에 확인한다

### 상황

부모는 아이에게 직접 연락하기 전에 오늘 상태를 알고 싶다.

### 앱이 해야 할 일

- 현재 상태를 한 문장으로 요약한다.
- 개입이 필요한지 알려준다.
- 상세 로그보다 흐름을 보여준다.

### 예시 메시지

```text
아직 개입이 필요하지 않아요.
오늘 공부 70분 중 25분 완료, 남은 시간으로 회복 가능합니다.
```

## 장면 8. 하루 마감

### 상황

취침 전 오늘 계획을 정리한다.

### 앱이 해야 할 일

- 완료한 것과 미룬 것을 짧게 정리한다.
- 내일 조정할 내용을 제안한다.
- 학생에게 실패감보다 마무리감을 준다.

### 예시 메시지

```text
오늘은 수학과 영어를 끝냈어요.
독서는 내일 20분으로 옮기면 괜찮아요.
```

## 장면 9. 주간 계획을 조정한다

### 상황

부모가 이번 주 계획을 보니 수요일 학원 시간이 길어 수학 공부량이 과해 보인다.

### 앱이 해야 할 일

- 과목별 주간 배분을 보여준다.
- 가용 시간이 부족한 날을 알려준다.
- 특정 과목을 다른 날로 옮기는 조정안을 제안한다.
- 조정 후 학생의 오늘 화면에 자동 반영한다.

### 예시 메시지

```text
수요일은 시간이 부족해 보여요.
수학 20분을 금요일로 옮기면 이번 주 계획이 더 편해져요.
```
