# 후속 설계사항

## 1. AI 코치 기능

MVP에서는 규칙 기반 판단을 우선하고, AI는 후속 단계에서 확장한다.

- 학생 성향별 말투 조정
- 미루는 이유에 따른 응답
- 하루 마감 회고 대화
- 계획 축소안 자동 제안
- 부모에게 보낼 요약 문장 생성
- 시험 대비기간의 과목별 공부 전략 문장 생성
- 장기 계획이 밀렸을 때 주간 재배분 제안

## 2. 위치 기반 기능

위치 기능은 제품 인상을 감시 앱으로 바꿀 수 있으므로 별도 검토가 필요하다.

- 집/학교/학원 도착 여부
- 이동 중 상태
- 지오펜스 기반 일정 전환
- 보호자 동의 절차
- 위치 데이터 저장 기간
- 학생에게 위치 사용 사실을 투명하게 보여주는 방식

## 3. 휴대폰 사용 시간 연동

Android와 iOS의 제약이 다르므로 플랫폼별 전략이 필요하다.

- Android 사용 통계 접근 가능성
- iOS 스크린타임/가족 공유 제약
- 특정 앱 사용 시간 표시
- 부모 알림 기준
- 학생에게 먼저 주지시키는 흐름

## 4. 부모 개입 정책

부모 알림은 신중하게 설계해야 한다.

- 몇 번의 회복 기회를 줄 것인지
- 어떤 상황에서 즉시 부모에게 알릴 것인지
- 부모가 알림 강도를 조절할 수 있는지
- 학생에게 부모 알림 예정 사실을 알려줄 것인지

## 5. 장기 통계

장기 통계는 동기부여가 될 수 있지만 압박감도 만들 수 있다.

- 완료율보다 루틴 안정성 중심
- 미완료 누적보다 계획 현실성 중심
- 칭찬 가능한 패턴 찾기
- 부모용 주간 요약
- 학생용 가벼운 성장 기록

## 5-1. 장기 학습 계획 고도화

MVP에서는 시험 일정과 반복 루틴을 기준으로 공부 시간을 분배한다.
후속 단계에서는 실제 성취도와 과목별 약점을 반영할 수 있다.

- 시험 범위 단원별 세분화
- 과목별 난이도와 약점 반영
- 오답노트 기반 복습 계획
- 수행평가와 숙제 마감일 통합
- 시험 직전 암기/문제풀이/복습 비율 자동 조정
- 계획 미이행 시 주간 단위 자동 재배분
- 방학 장기 계획 지원

## 6. 온보딩

초기 설정은 짧아야 한다.

- 학생 나이대
- 기본 취침 시간
- 학교/학원 기본 일정
- 부모 알림 강도
- 하루 공부 계획 입력 방식
- 학생에게 앱의 목적을 설명하는 짧은 안내

## 7. 개인정보와 신뢰

학생 대상 서비스이므로 데이터 최소 수집을 기본으로 한다.

- 수집하는 정보와 이유 설명
- 부모/학생에게 보이는 정보 구분
- 민감 정보 저장 기간
- 위치/휴대폰 사용 데이터의 별도 동의
- 삭제 요청 처리

## 8. 유료화 가능성

MVP 검증 전에는 유료화를 전면에 두지 않는다.

- 무료 기본 루틴 코치
- 가족 단위 프리미엄
- AI 코치 고도화
- 주간 리포트
- 여러 자녀 관리

## 9. 실험 항목

- 학생에게 가장 부담 없는 알림 톤
- 부모가 원하는 최소 요약 수준
- 계획 조정 요청 버튼의 사용 빈도
- 공부 시작 전환에 가장 효과적인 메시지
- 하루 마감 화면의 재사용률
- 시험 D-day 표시가 동기부여인지 압박인지
- 학생에게 주간 계획을 얼마나 보여주는 것이 적절한지
- 부모가 입력 가능한 시험 정보의 적정 수준
