# 모바일 앱 전환 체크

웹앱은 제품 흐름 검증용이며, 최종 모바일 앱 전환을 전제로 한다.
계산 로직과 알림 판단은 UI 컴포넌트 밖에서 유지한다.

## 재사용할 것

- 장기 계획 생성 엔진: `src/domain/longTermPlan.ts`
- 하루 코치 엔진: `src/domain/dayCoach.ts`
- 평시 루틴 생성 엔진: `src/domain/routinePlan.ts`
- 가족 생활 리듬 시간 블록 생성: `src/domain/familySchedule.ts`
- 알림 조건 판단: `src/domain/notificationPolicy.ts`
- 화면 응답 타입: `src/types/study.ts`
- 모바일 디자인 기준: `src/styles/designTokens.ts`

## PWA 적용 가능 범위

- 홈 화면 설치 경험 검증
- 웹 푸시 가능성 검증
- 학생 재방문 흐름 검증
- 오프라인 캐시가 필요한 화면 후보 확인

PWA는 최종 목적지가 아니라 모바일 앱 전환 전 검증 단계로 둔다.

## 모바일 앱 전환 시 새로 구현할 것

- React Native 또는 Flutter 등 앱 기술 스택 선택
- 앱 프로젝트 생성
- iOS/Android 푸시 알림 연동
- 앱 권한 요청과 거부 상태 처리
- 앱 로그인/세션 처리
- 가족 초대 흐름
- 백그라운드 알림과 절전 정책 대응
- 앱스토어/플레이스토어 배포 준비
