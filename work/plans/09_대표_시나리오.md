# 대표 시나리오

## 목적

이 문서는 1차 MVP를 개발할 때 기준이 되는 대표 학습 시나리오다.
화면, 계획 생성 로직, mock 데이터, 검증 시나리오는 이 문서를 기준으로 만든다.

## 1. 장기 계획. 한 달 시험 준비

### 한 달 계획 구조

| 기간 | 목표 | 공부 강도 |
|---|---|---|
| 시험 4주 전 | 개념 빈틈 확인 | 낮음~중간 |
| 시험 3주 전 | 문제풀이 시작 | 중간 |
| 시험 2주 전 | 시험범위 집중 회독 | 높음 |
| 시험 1주 전 | 암기/오답/실전 | 매우 높음 |

### 시험 4주 전 전략

핵심은 `무너지지 않는 루틴 만들기`다.
이 시기에는 과하게 하지 않고, 매일 공부 흐름을 유지하며, 과목별 구멍을 확인한다.

예시:

- 수학: 개념 + 기본 문제
- 영어: 단어 루틴
- 과학: 개념 읽기
- 국어: 학교 프린트 정리

### 시험 3주 전 전략

핵심은 `문제풀이 시작`이다.
개념을 완전히 끝내려 하기보다 기본 문제와 대표 유형을 풀면서 부족한 부분을 찾는다.

예시:

- 수학: 기본 문제와 유형 문제
- 영어: 단어 루틴 + 독해
- 과학: 개념 확인 문제
- 국어: 지문 문제풀이

### 시험 2주 전 전략

핵심은 `시험 모드 전환`이다.
이때부터는 학교 시험 범위에 집중하고, 새로운 범위를 넓히기보다 회독과 반복을 늘린다.

이 시기에는:

- 학교 시험 범위 올인
- 오답 반복
- 암기 회독
- 시간 압축

### 시험 1주 전 전략

핵심은 `판단 제거`다.
시험 직전에는 공부량을 늘리는 것보다 오늘 무엇을 할지 고민하지 않게 만드는 것이 중요하다.

우선순위:

- 반복
- 암기
- 오답
- 교과서
- 예상문제

## 2. 중기 계획. 주간 계획

주간 계획은 `현실 조정 장치`다.
하루 단위로 실패 여부를 판단하기보다, 주간 총량을 관리하고 주말 보정을 허용한다.

### 평상시 주간 구조

| 과목 | 목표 |
|---|---|
| 수학 | 개념 3단원 + 문제 |
| 영어 | 단어 300개 + 독해 |
| 과학 | 학교 진도 정리 |
| 국어 | 문제집 20지문 |

핵심:

- 하루 실패 허용
- 주간 총량 관리
- 주말 보정 가능
- 과목별 흐름 유지

### 시험 2주 전 주간 구조

| 과목 | 목표 |
|---|---|
| 수학 | 시험범위 2회독 |
| 영어 | 교과서 암기 |
| 과학 | 암기표 반복 |
| 국어 | 예상문제 |

이 시기에는 새로운 것을 늘리기보다 반복을 우선한다.

- 새로운 것: 지양
- 반복: 우선
- 오답/암기/회독: 강화

## 3. 단기 계획. 일일 미션

일일 계획은 시간표 방식보다 `미션 방식`이 유지율이 높다.
학생 화면에는 시간표 전체보다 오늘의 미션 묶음으로 보여준다.

### 오늘의 미션 구조

#### 필수

- 수학 오답 20개
- 영어 단어 40개
- 과학 개념 3페이지

#### 추가

- 국어 독해 2지문

#### 남으면

- 사회 암기

## 4. 시험 임박 모드

시험 직전에는 공부량 증가보다 판단 제거가 중요하다.
앱은 학생에게 선택지를 많이 주지 않고, 반복해야 할 미션을 명확히 제시한다.

우선순위:

1. 오답
2. 암기
3. 교과서
4. 예상문제
5. 짧은 반복 회독

## 5. 앱 동작 기준

- 장기 계획은 시험까지 남은 주차에 따라 학습 강도와 미션 성격을 바꾼다.
- 주간 계획은 하루 실패를 흡수하는 현실 조정 장치로 동작한다.
- 일일 계획은 시간표가 아니라 필수/추가/남으면 미션으로 보여준다.
- 시험 2주 전부터는 새로운 학습보다 반복, 회독, 오답, 암기를 우선한다.
- 시험 1주 전에는 학생이 무엇을 할지 고민하지 않도록 판단을 제거한다.
- 학생 화면은 항상 `오늘 지금 시작할 미션`을 가장 먼저 보여준다.
