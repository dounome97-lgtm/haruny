# UX 품질 체크

## 확인 범위

- 학생: `/`, `/student/week`, `/student/adjustment`, `/student/closing`
- 부모: `/parent/reassurance`, `/parent/today-adjustment`, `/parent/week-adjustment`, `/parent/day-summary`, `/parent/notifications`
- 계획: `/parent/exam-prep`, `/parent/exam-prep/subjects`, `/parent/exam-prep/review`, `/parent/routine`
- 가족: `/family`

## 확인 결과

- 첫 화면은 테이블, 검색 필터, 엑셀식 목록 없이 현재 상태와 다음 행동을 먼저 보여준다.
- 학생 화면은 완료율이나 감시 문구보다 `지금 할 일`, `회복 가능성`, `끝냈어요` 흐름을 우선한다.
- 부모 화면은 상세 로그 나열보다 안심 요약, 개입 판단, 현실적인 조정안을 먼저 보여준다.
- 실패 상황은 처벌이나 통보가 아니라 `줄이기`, `내일로 옮기기`, `회복 가능` 중심으로 표현한다.
- 학생 첫 화면의 부모 개발 흐름 링크를 제거해 역할이 섞이지 않게 했다.
- 긴 문구가 모바일 카드와 버튼에서 밀려나지 않도록 기본 줄바꿈 규칙을 보강했다.
- 주요 화면은 모바일 앱 화면처럼 단일 주 행동과 하단 주요 버튼 중심으로 유지한다.
- 새로 띄우는 확인, 선택, 입력 보조 UI는 브라우저 기본 `alert`, `confirm`, 기본 시간 선택창 대신 앱 안의 모달 또는 바텀시트를 기본으로 사용한다.
- 삭제, 초기화, 되돌리기 어려운 행동의 확인 모달에는 대상 이름, 영향, 취소 행동을 함께 보여줘 사용자가 맥락을 잃지 않게 한다.
- 시간 선택처럼 반복 입력이 많은 UI는 앱 안의 모달에서 빠른 조정 버튼과 명확한 선택 칩을 함께 제공한다.

## 남은 확인

- 실제 기기 폭에서 시각적 스크린샷 점검
- 실제 사용자 입력값이 길어질 때의 카드 높이와 버튼 줄바꿈 점검
- MVP 시나리오 검증 단계에서 화면 간 진입 경로 재점검
